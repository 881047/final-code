## §0 对象与冻结定义

- **L2 = 18 列**：base 25 − 7（DEAD{disp_20, weekday} + DUP{rel_mom_60, xrank_mom_60,
  xrank_pvol_20, rev_5} + NOISE{upper_wick}）。**唯一权威源 = `featclean_chain.py` 常量**
  （DEAD/DUP/NOISE）；实现须引用同源常量、不得硬编码名单；执行器内置断言（base=25、L2=18）。
- **受影响对象（3 工件）**：`dlv2_production.pt`（消费 w2/t3/k100 主信号位）、
  `a1_production.pt`（w2_blend 的 Ā 支）、`rl_production.pt`（w2_tri 三流之一）。
  三件均已核实 `feature_cols` = 25 列全集（含拟删 7 列）。
- **分对象采纳原则**：以**损失族**为单位裁决——dlv2 与 rl 同属 **MSE+RankNet λ=1 族**；
  a1 = **ListMLE 族**。各族独立过门/独立采纳；单对象负 ⇒ 该对象维持 25 列
  （混合版本无配置障碍，工件级独立）。
- **单变量纪律**：全链唯一变量 = 特征列子集（25↔18）；配方/种子/折界/窗/超参/评估格
  逐字不动。任何顺带改动 = 另立链或勘误后重冻。
- **数据快照**：研究线 worktree 面板冻结 2026-09-30（G8 门强制）；生产侧（D:\Final）
  阶段 2 执行日为面板端点（当日配对）。

## §2 阶段 1：配方迁移双检（OOS 折叠格；先于其他阶段）

### 1a. ListMLE 族（a1 对象）

- **参考（25 列）**：`experiments/adopt_blend_20261014/stream_A1.parquet`（#124 注册流；
  6 种子均值池化；**2021-01-04 → 2026-09-21，1,387 日**，folds 1–3）。
- **新臂（L2 列）**：新执行器 `experiments/l2adopt_a1_20261016/scripts/l2adopt_a1_chain.py`
  ——**逐字镜像** `adopt_blend_20261014/_train_a1_folds.py` 覆写模式（ARMS=("A1",) +
  OUT_DIR 覆写；训练函数逐字复用 `ab_chain.run_all` 家族），**唯一新增 = bundle 特征列
  替换**（`dataclasses.replace(bundle, feature_cols=L2_18)`；同 featclean 先例）。
  folds=[1,2,3]、种子=(7,21,99,5,13,123)、折界/窗/超参逐字不动；产物 = 逐种子流 +
  均值池化流（对齐参考格式）；同源 diff 存证（vs `_train_a1_folds.py`）照 #136 体例。
- **判据（G1a，全满足 = PASS）**：均值池化口径 ΔIC(L2−A1)：
  ① 点估计 > 0；② NW-t ≥ 2；③ block 置换 p < 0.05（BLOCK=10，N_PERM=2000，
  seed=20261015，同 #130/#136）；④ **逐种子 6 个里 ≥5 同正**（源：本链逐种子流 vs
  adopt_blend `parts_perseed/` 对应流；若覆盖不全 ⇒ 该子项如实降级为报告级并登记）。
- **G0 仪器门**：新臂流与参考流逐日/逐键行对齐（同 #136 J0 口径）；L2 列数断言。

### 1b. MSE+RankNet λ=1 族（dlv2/rl 对象）

- **协议**：**逐字镜像** `scripts/rankloss_chain.py`（判据链 #14 臂 B = #8 折训练路径 +
  RankNet pairwise（batch 内同日相邻对，λ=1，早停 = val MSE））的 `train_fold_rankloss`。
- **双臂配对新鲜**（吸收 §1 第 5 条）：{25 列, L2 列} × 同协议同日跑；
  种子集 = `SEED_SETS[0] = (7,21,99,5,13)`（5 网）；folds 0–3 全折（dlv2 FOLD_EDGES）。
  **加跑条款**：本集过门 ⇒ 加跑 `SEED_SETS[1]`（5 网）复核（双集同向 = 更强结论）。
- **输出序列化**：训练数值路径逐字（含集合均值池化），仅输出改为**逐种子保留**
  （同 #136 先例：序列化差异零语义，diff 存证）；主读数口径 = 与参考协议一致的
  集合均值池化。
- **判据（G1b，全满足 = PASS）**：同 G1a 结构——ΔIC 均值池化主读数 + NW-t ≥ 2 +
  perm p < 0.05 + **逐种子 ≥4/5 同正**。
- **对照锚（不设门）**：本链 25 列臂 vs 10-14 版 `rankloss_ss7_21_99_5_13.parquet`
  的逐日截面秩相关（预期 ~0.9 量级，家族噪声语境随判读登记）。

族过门 ⇒ 对应对象进入阶段 2；族不过/为负 ⇒ 该对象**不采纳**（分对象结论，全链继续）。

## §4 阶段 3：组合层忠实账本回放（fold 流；含成本）

- **信号源**（相对设计草案 §2 阶段 3 的细化改进：改用阶段 1 折叠 OOS 流——与
  #124/#131/#132 全部组合层判据**同源**，比全史 in-sample 面板更严格；此改进随本
  预注册生效并登记）：
  - dlv2/rl 信号 = 阶段 1b 的 {L2, 25} 两臂流；a1（Ā）= 阶段 1a 的 {L2, 25} 两臂流；
  - blend/tri 合成 = 现行口径重算（D = 0.5·rank(Ā)+0.5·rank(dlv2)；T3 三流秩合成）。
- **回放**：`tierfix_replay.arm_faithful` 现行复用；**主窗口 = 2021-01-01 → 2026-09-30**
  （各流共同覆盖，对齐 a1）；纯 dlv2 轨另报 2019+ 延伸窗。tier = w2（2 万 top2/keep4）
  + t3（100 万 top10/keep20）+ k100（报告级）。
- **仪器双读数**：halt-off（主，可比性）+ halt-on（副，生产语义）。
- **判据**：
  - **M1（主门，w2 轨）**：Δnet(L2−ref) ≥ 0 且 |ΔMDD| ≤ 2pp（恶化超限否决）；
    月度配对 t 随报。
  - **M2**：t3 轨 Δnet 与 w2 同向（反向 ⇒ 出「分轨分歧」结论交用户仲裁）。
  - **M3（量级限定）**：|Δnet| 落入不可分辨噪声带（参考：#165 单臂跨运行 0.1–0.24pp IC；
    ranknet 族更宽）⇒ 报「读数在噪声内」，不得作采纳依据。
  - k100 / blend / tri = 报告级。
- **成本**：CPU 回放 ~10–20 min/臂轨。

## §5 阶段 4：切换（用户拍板；无自动执行）

- **默认预案**：直接切换（先例：#13「候选直接入主生产信号位」、#14 损失换版）；
  **正式拍板于阶段 3 读数报用户后**（允许届时候选「影子 60 日」替代方案）。
- **切换三件套**：① 非交易时段执行；② 版本日记（sha + asof + 回退点）+ **回退演练一次**
  （换回 = 分钟级）；③ 切换后 **2 周增强监盘**（净值/告警/换手三核对），异常即回退。
- **范围**：仅阶段 3 PASS 的对象；blend/tri 观测程序 seam 登记（不重置 60 日时钟）。
- **本阶段一切动作须显式人工指令；本预注册不含任何自动切换。**
