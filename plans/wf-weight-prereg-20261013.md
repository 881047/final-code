## §1 数据与口径（**冻结**）

1. **流**：E2 = `experiments/arch_20261009/stream_E2.parquet`；
   dlv2 = `D:\Final\data\reports\dlv2_ss7_21_99_5_13.parquet`；
   RL2 = `D:\Final\data\reports\rankloss_ss7_21_99_5_13.parquet`（含 fold 列）。
   **全部 inner join 到共同 (date, product)**（G5）；每日保留 ≥5 只且 pred/y 有限的股票。
2. **y 口径（双口径，主判以 primary）**：
   - **primary = 报告 vintage**：rankloss 流的 `y_ret`（已核实与 dlv2 流逐位相等，8,043,253/8,043,253）；
   - **comparability = E2 vintage**：E2 流自带 `y_ret`（与 #122 读数口径一致，便于对账；
     已知与报告 vintage 有 11,899/8,043,240 行不一致，max|Δ|=0.573）。
   **所有采纳相关门只看 primary**；comparability 全表并报。两口径结论若相反 ⇒ 记「vintage 敏感」，按 primary 判。
3. **折**：RL2 流 `fold` 列（已核实：fold0=2019-01-02..2020-12-31，fold1=2021..2022，
   fold2=2023..2024，fold3=2025-01-02..2026-09-21）。评估段末 ≤ **2026-09-30**（G8 隔离线）。
4. **IC/ICIR**：逐日截面 Spearman（`groupby(date).rank(pct=True)` 后与 y 的日内秩相关）；
   每日 <5 只 ⇒ 该日丢弃；ICIR = mean(IC)/std(IC, ddof=1)。
   **混合流** = `w·rank_pct(E2) + (1−w)·rank_pct(dlv2)`（各自日内百分位秩后线性组合）。
5. **显著性**：**循环块自举**（块长 20，B=2000，种子 20261013），对 (候选 IC 序列, RL2 IC 序列)
   成对重采样算 ΔICIR 分布；**禁用循环移位置换**（#122 实证 p≡1 退化）。
   实现构型与 `lead_check_20261013/block_stats.py` 相同并登记出处。

## §2 臂设计（**冻结**）

| 臂 | 定义 | 说明 |
|---|---|---|
| **A_eq** | w = 0.5 固定 | **先验声明点**（#122 候选；唯一无需选择的权重） |
| **A_wf** | 走前权重 w\*(t) | 折 t 的 w\* 只用**该折起点之前**的历史：估计窗 = [2019-01-02, fold_t 起点 − 1 交易日]（expanding）；在网格 w ∈ {0.0, 0.1, …, 1.0}（11 档）上以估计窗内 ICIR 最大者胜出；**平手取更接近 0.5 的档**；**fold0 无历史 ⇒ w\*(0) := 0.5**（协议规定，非选择） |
| **A_base** | RL2（生产位） | 基线 |
| 登记（不作门） | E2+RL2+dlv2 三流等权；w ∈ {0.2, 0.8} 端点 | 供前沿对照（#122 前沿：ICIR 峰 ≈ w0.2） |

**评估段**：各臂在同一共同日期集合上逐日评估；A_wf 在折 t 内用 w\*(t)（折间权重可变）。

## §3 判据（**冻结，全部先于跑数**）

| 编号 | 判据 | 门槛 |
|---|---|---|
| **P1 ⭐主** | A_eq − A_base 全期 ΔICIR（primary y） | 循环块自举 **CI95 下界 > 0**，且双侧 **p < 0.025**（本批主门 2 个 ⇒ 按 α/2 折算报告）；同时报配对 ΔIC，须 **≥ −0.005**（IC 不劣容忍线） |
| **P2 ⭐折稳健** | 逐折 ΔICIR（primary y） | **fold1–3 合并 ΔICIR 的块自举 CI95 > 0**（这三折才有走前历史，是本设计的承重段），**且每折 ΔICIR ≥ −0.03**（fold0 的 −0.0214 在容忍带内；若 ≤ −0.03 ⇒ 登记结构性风险，不采纳） |
| **P3 选择增量** | A_wf − A_eq 全期 ΔICIR | CI95 **含 0** ⇒ 选择无增量，**采纳候选定格 w=0.5**；CI95 > 0 ⇒ 登记「走前选择更优，需独立复验」——**仍不直接采纳**（等权是唯一可先验声明的点，w\*(t) 依赖估计窗构造） |
| **P4 选择稳定性** | w\*(t) 的重估分布 | 对每折估计窗做 200 次块自举重估 w\*，报 IQR；**任一折 IQR > 0.3 ⇒ 声明「走前选择在本数据上不稳定」**，无论 P3 结果，主判以 A_eq 为准 |
| **P5 ⭐阴性对照** | 仪器必须能失败 | (a) y 日内置换后全部臂的 ΔICIR CI95 必须覆盖 0 且 \|mean IC\| ≤ 0.025；(b) `E2+rand`（dlv2 列日内置换后与 E2 等权）对 A_base 无优势。任一失败 ⇒ 本批仪器判废，修好重跑 |
| **登记** | 效应量 | ΔICIR 相对跑间噪声（#116 的 0.00259 档，仅量级参考）与 \|ΔIC\|/MDE(0.0164, #98) 并报 |

**通过 = P1 ∧ P2 ∧ P5**（P3/P4 决定「采纳形态：等权 or 走前」，P1 单独不构成采纳）。
**即便全过，本批也只到「值得另立采纳预注册」，不改生产**（沿用 #122 §4-2）。
