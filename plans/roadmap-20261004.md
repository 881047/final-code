## 判据链 #1 遗留的三个事实（路线图的输入）

1. 随机对照 D（−10.5%/MDD −11.5%）打赢 rule 基线 A（−32.9%/−54.5%）⇒
   **rule_reversal 构造负边际**，但归因未知（静默闸？退出带？集中度？信号本身？）。
2. 模型方向臂 OOS IC +0.014~0.017（双种子集同向，t>2）但组合层不可用
   （dir_acc 0.51、配对 t≈0、成本 11-16×）⇒ **信息存在，门限/换手经济学失败**。
3. 全部臂（含随机）2017-09 以来绝对收益为负 ⇒ **"周频轮动 + 2 万"这个前提
   本身缺少"什么都不做"的参照**——静态持有地板缺失。

## Phase 1 · A' 归因消融 + 静态参照（判据链 #2）—— 诊断，最便宜

- 内容：rule 构造三开关的单开关消融（S1 去静默闸 / S2 去退出带 / S3 top_n=4
  分散 / S4 top_n=1 集中）+ **E 静态持有臂**（期初随机 2 只拿满全程，
  "什么都不做"的地板）+ A0/D 锚臂重跑对齐。
- 判据：**诊断性**——产出各臂 vs D 的周配对差与 MDD，识别负边际贡献开关；
  新基线候选 S* 按预注册顺序取第一个配对差均值 > 0 且 t > 0 者。
- 产出门：S* 存在 → 进 Phase 2 的比较基线；不存在 → 构造族判负，
  Phase 2 降级为"只做诊断读数"，Phase 3 是否立项看战略问题。

## Phase 2 · B' 门限经济学（判据链 #3）—— 零训练（用 #1 的缓存 OOS 流）

- 内容：p_up 门限 0.55 / 0.60 / top_n=1 三变体（预先声明，防事后挑），
  双种子集，与 Phase 1 的基线（S*，否则 A0/D）配对。
- 判据：C2' 配对 t≥2 且均值>0、C3' MDD 容差 2pp、C4' 成本 ≤基线×1.25，
  双种子集同向才 adoption_ready。
- 预期管理：IC 0.014 撑不过 5 元佣金地板是大概率，判"否"落在判据上即收口。

## Phase 3 · LightGBM 截面臂（判据链 #4）—— 一次性买断"树 vs 该面板"

- 内容：老盘同构的树模型（LightGBM，截面因子 → 21 日行业中性超额标签的
  日频移植）走同一净化折叠 + 同一组合层两轴。
- 立项前置条件：① Phase 1/2 的读数显示"构造可修"或"参照系成立"；
  ② 环境可用（lightgbm 包装得上——SAC 曾拦 sklearn 的 pyd，需实测）。
- 判据：与 #1 同构（信息层 + 组合层两轴 + 双种子集）。

## Phase 4 · 收口/转向 决策点（用户拍板）

- 若 Phase 1-3 全部判否：fterm-A 的**信号层**探索诚实收口，终端骨架保留
  （数据链/看板/工件纪律可承载任何信号），战略问题提上桌面——
  fterm-A 与 W2 定位重叠，差异化价值是什么（终端 vs 独立策略线 vs 错位频段）。

## 纪律（全程不变）

预注册先 commit 再跑数；判据常数冻结于预注册文档并在执行器里用常量实现；
读数无论好坏全登记；多重比较处必须预先声明候选集合与选择规则；
**判决词一律由用户填写**；证据包进 `experiments/` 随 commit 存档。
