# 设计文档 · 宽组合影子轨 k=100（B8 · 不占判据链号 · 仅设计，待用户拍板）

> 依据：#24 R4 宽度表——组合层判据在 k=2 下需 221 年检出（k=1 需 867 年），
> 而 k=100 超额 +16.3bp（t=+2.33）、k=450 +15.1bp（t=+2.76）已显著。
> #24 R5 已把采纳判据改建立在截面量（k=100/450）上，但 `paper_tracks` 无对应轨道
> ⇒ 组合层长期缺测量仪器。2026-10-14 B 系列计划 B8。
> **本文档只做设计与拍板请求，不改 config.yaml。**

## 1. 轨道定义（建议冻结形态）

| 项 | 内容 |
|---|---|
| 轨名 | `paper_tracks.k100`（观测轨，与 w2/t3/w2_blend 并列） |
| 构型 | equity=100,000,000（1 亿假设资金）；k=100 等权（top100，keep_n=200）；max_symbols=100 |
| 信号 | 与主轨同源（dlv2 + EMA，`signal.mode` 现行位）；**本轨不改信号**，只改持仓宽度 |
| 撮合 | PaperBroker 同引擎；单票预算 100 万（整手约束下 95 元以下股票均可 ≥1 手，可负担性显著好于 top2 的 27% 买不起率） |
| 状态库 | `data/state/fterm_k100.db`（独立账本） |
| 调度 | 挂入现有 20:05 日任务（runner 按 tracks 循环，增量成本 ≈ 每日多 100 次 paper 询价） |

## 2. 目的与非目的

- **目的**：给组合层造第一个可裁决的收益测量刻度（#24 R4：k=100 的 t 已达 2.33，
  约 3 年账本即可在 80% 功效下检出实测效应）；为 B1（退出引擎）等组合层候选
  提供宽组合对照读数；长期监控「预测层→组合层」传导。
- **非目的**：不服务真实资金（1 亿为假设）；不作为任何采纳门的主判据
  （采纳判据仍按 R5 建立在截面量上）；不产生交易建议。

## 4. 风险与代价

| # | 风险 | 缓解 |
|---|---|---|
| 1 | 日任务时长增加（100 标的询价/记账） | 预估 <2 分钟增量；先影子跑 3 日观测时长再正式入轨 |
| 2 | 状态库体积增长（100 持仓 × 日） | SQLite 单表年增 ~10 万行，可控 |
| 3 | 与 R5「截面量判据」的双轨判据混乱 | 本轨只观测不裁决；docs/02 登记轨语义时写明 |
| 4 | 换手与成本假设在 100 万单票预算下与 w2 档不可比 | 报告读数时按轨分列，不做跨轨收益直比 |

## 5. 验收（轨道级，非收益门）

① 权益恒等式（每日）；② 部署率与日任务时长；③ 与 #24 R4 截面读数的方向一致性
（季度粒度对账）。**不设收益门**。
