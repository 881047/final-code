# 臂 C 的 14 种子确证性实验 · 预注册（2026-10-09）

> 依据：`docs/audit-model-20261009.md` §7.4（臂 C 2 种子四折读数：IC +0.0514 / ICIR +0.660 /
> 配对 t **+1.66** / PBO 0.514，**方向全正但未达门槛**）。
> 本预注册**先于实验冻结判据与种子集**；判决词由用户填写。

---

## §一 目的（单一问题）

臂 C 在 **2 种子**下相对 F0 的 IC 改善为 **+0.0067（+15%），配对 t = 1.66**，未达 t ≥ 2。
本实验回答**唯一一个问题**：

> **把集成规模从 2 网扩到 14 网（= 生产位配置），臂 C 的 IC 改善能否达到预注册显著性门槛 t ≥ 2？**

这是一个**关于集成方差**的假设检验，**不是**"再试一次直到显著"。为守住这条线，
本预注册冻结以下全部要素。

---

## §二 冻结（逐字不变）

| 项 | 冻结值 | 说明 |
|---|---|---|
| **种子池** | `(7,21,99,5,13,123,2024,42,314,2027,101,202,303,404)` = **14 个** | 与 `scripts/train_production.py::SEED_SETS` **逐字相同**（生产位口径） |
| **折界** | `2019-01-01 / 2021-01-01 / 2023-01-01 / 2025-01-01` + 面板末日 | 与臂 A/B/C 既有四折**逐字相同** |
| **特征（F0）** | 现役 **25** 个 | 不变 |
| **特征（C）** | 现役 25 + 7 个幸存外部因子 = **32** 个 | 与 §7.2 幸存者表逐字相同 |
| **损失** | **纯 MSE** | 与臂 C 2 种子读数一致（**不含** RankNet；本实验只动"集成规模"一个变量） |
| **超参** | MAX_EPOCHS=30, PATIENCE=5, BATCH=4096, LR=1e-3, WD=1e-5 | 与既有链一致 |
| **训练/验证切分** | `val_cut = 0.85 × len(train)` | 与既有链一致 |
| **去重口径** | max\|ρ\| vs 现役 ≤ 0.7 | 已通过（最高 0.641） |

**关键纪律：对照 F0 必须同为 14 种子。**
若用「C_14 vs F0_2」比较，则"特征"与"集成规模"两个变量混淆，结论不可解释。
故本实验**同时训练 F0_14 与 C_14**（各 4 折 × 14 网 = 56 次训练，共 112 次）。

---

## §三 主判据（一次性判定）

| 层级 | 判据 | 门槛 |
|---|---|---|
| **主判据** | 逐日配对 t（C_14 − F0_14），逐日截面 Spearman IC | **t ≥ 2 且 ΔIC > 0** |
| 辅判据 1 | ICIR(C_14) > ICIR(F0_14) | 用户指定的稳定性主判据 |
| 辅判据 2 | regime 4 层（趋势×波动）最小分层 IC > 0 | 制度稳健性 |
| 辅判据 3 | PBO（CSCV，8 块） | < 0.5 |
| 仪器门 | 阴性置换 tripwire \|mean IC\| ≤ 0.025；流 100% 非空 | 任一失败 ⇒ 读数作废 |

**判定词**：
- 若**主判据通过** ⇒ 臂 C 达到采纳门槛，进入 Phase 4（组合层校验）。
- 若**主判据不通过** ⇒ **臂 C 判负并结案**，不再做"加更多种子/换种子集"的尝试。

---

## §四 一次性判定纪律（不可违反）

1. **种子池与判据在跑之前冻结**（即本文档），跑完**只判定一次**。
2. **禁止**：跑完后替换种子、增删种子、改判据、改门槛。
3. **禁止**：按中间读数提前终止或延长（中途读数**仅作诊断展示**，不构成判定）。
4. **禁止**：在 F0_14 与 C_14 之间使用不同的超参或切分。
5. 若运行中断，**从断点续跑同一配置**，不得改变任何冻结项。

---

## §五 已知局限（如实登记）

1. **本实验不直接对比生产位 dlv2 工件**。F0_14 是「同代码、同折、同种子池、纯 MSE」的
   复现基线，与生产工件的差异在于**损失**（生产位含 RankNet λ=1）与 **val 比例**（生产位 0.10）。
   故本实验只回答"特征扩充在固定配置下的增量"，**不等于**"C_14 优于生产工件"。
   若主判据通过，**下一实验**才是"C_14 vs 生产工件"。
2. **GPU 非确定性**：同码同种子背靠背 `max|Δpred| ≈ 2.8e-3`（docs/02）。F0_14 与 C_14
   在同一台机器、同一次运行内训练，故差异被控制在同一噪声水平内；但**不保证逐位可复现**。
3. **算力成本**：112 次训练，按既有链实测约 **8–12 小时**（RTX 4060）。
4. **多重检验**：这是针对臂 C 的**第 2 次**检验（第 1 次为 2 种子）。
   按 Bonferroni，若要在 α=0.05 下保持族错误率，门槛应更严（≈ t ≥ 2.24）。
   **本预注册仍采用 t ≥ 2**（与项目既有门槛一致），但**在结论中会同时报告该放宽效应**。
