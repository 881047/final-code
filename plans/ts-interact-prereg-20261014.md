## §0 阶段一：注入阳性对照标定（**先于真臂，冻结**）

| 项 | 冻结内容 |
|---|---|
| **注入信号** | 人造列 `inj = 0.05 × z(known_factor)`，known_factor = 现役列中 IC 最强者（`mom_5`，#114）；注入强度 0.05（预注册 §0 冻结，1.9× 跑间噪声） |
| **注入方式** | `x_injected = x_rank Gauss + inj`（加在已知因子的白化值上）⇒ 2 臂 A/B：基线（25 列）vs 注入臂（26 列） |
| **训练** | fold0 × seeds(7,21)（快速标定；同 #129 featclean train_fold 冻结实现） |
| **检出判据** | 注入臂 vs 基线 ΔIC ≥ 0.00259（1× 跑间噪声）**且** 方向为正 ⇒ 管线分辨率足够 |
| **作废条款** | **ΔIC < 0.00259 ⇒ 仪器无分辨率，本链整体作废**（不跑真臂；0.05 强度是本链设计精度的下限声明） |
