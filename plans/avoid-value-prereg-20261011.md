## §二 B 的设计（**冻结**）

### 2.1 输出：三档回避名单（不是"买入名单"）

| 档 | 定义 | 用途 |
|---|---|---|
| **AVOID-10** | 最弱档（预测秩 ≤ 10%） | **强回避**：已有仓位者优先卖出 |
| **AVOID-30** | 最弱 30% | 一般回避 |
| **WATCH** | 最弱 30%~50% | 观察 |

**⚠ 本链不产出"买入名单"** —— #30 已证判强侧仅捕获 47.8%，
且 top-10 内 IC 为负。**只做减法。**

### 2.2 价值量化（**这是 B 的核心**）

对每个回避档，报：
1. **被回避组的实现超额**（相对当日截面均值）；
2. **对照组**（同档规模的随机组）的实现超额 ⇒ **差值 = 回避的净价值**；
3. **成本覆盖比** = 回避价值 ÷ 该档换手所需成本（用 `fterm/contracts.py` 口径）；
4. **时机敏感性**：不同调仓频率下，价值是否被成本吃掉。

### 2.3 判据（**冻结**）

| 编号 | 内容 | 通过条件 |
|---|---|---|
| **B1 回避有效** | AVOID-10 的实现超额（相对随机同规模组） | **< 0 且 NW-t ≤ −2** |
| **B2 成本可覆盖** | 回避价值（bp）÷ 成本（bp） | **≥ 1.0**（否则判"有效但不可用"） |
| **B3 分档单调** | AVOID-10 / AVOID-30 / WATCH 的价值单调 | 不单调 ⇒ 登记异常 |
| **B4 时间稳定** | 前段 / 后段分别报 | 两段同号；后段不塌陷 |
| **B5 regime 诚实** | 必须报市场状态分层（涨/跌月） | 缺 ⇒ 不合格 |

研究产物落在 worktree。生产 `data/` 在 `.gitignore` 内 ⇒ 产物只进 worktree。

### 3.2 逐日留痕

每日记录（追加，不覆盖）：
`asof, n_stocks, 各档只数, 该档预测名单的哈希, 实现值（待结果可知后回填）`。

### 3.3 判据（**冻结**）

| 编号 | 内容 | 通过条件 |
|---|---|---|
| **C1 累积可运行** | 每次运行追加一行，且**幂等**（同 asof 不重复） | 失败 ⇒ 判废 |
| **C2 前瞻无泄漏** | 只使用 as-of 及以前的打分；实现值只用于**已过期**的 asof | 违反 ⇒ 判废 |
| **C3 滚动稳定性** | 累积 ≥ 20 个交易日后，报滚动 20 日命中率 | 不足 ⇒ 报"样本不足"（不判否） |
| **C4 与历史相容** | 前瞻段的命中率落在 #30 历史区间内 | 显著偏离 ⇒ 登记并调查 |

## §六 已知局限（**如实登记**）

1. **生产 `ema_state` 只有 1 个 as-of**（2026-10-09）⇒ **C 的前瞻段必然从今天开始**，
   不可能有历史回溯；这是**设计事实**，不是缺陷。
2. **回避 ≠ 做空**（A 股只做多）⇒ B 的价值只能体现为"少亏"，不能体现为"赚"。
3. **被回避组的表现含"下跌 beta"**（弱股在市场下跌时跌更多）⇒
   **B5 的市场状态分层是必需的**，否则会把 beta 当成能力。
4. 成本口径为近似（#29 已登记）。
