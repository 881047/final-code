## §0 对象与冻结定义

- **臂 EW（唯一新臂）** = 纯 ListMLE + 样本权重。权重定义（**冻结单一形式，不扫参**）：
  - `w_i = 2` ⇔ 训练样本 (d, c) 在**样本日 d**「触及涨跌停」；否则 `w_i = 1`；
  - 触及口径 = #130 `limit_feat_build` 逐字：`touched_up = high ≥ up_limit − 1e-6`、
    `touched_dn = low ≤ down_limit + 1e-6`、`hit = touched_up ∨ touched_dn`
    （含炸板；判定源 = 面板列 up_limit/down_limit，2017 起全量覆盖）；
  - 脏日 `DIRTY = {2021-09-20, 2021-09-21}` 权重一律 = 1（判定不可用，保守处理）；
  - 权重**仅作用于训练段样本的损失**（val / 早停 / 评估格一律不变）。
- **损失形态（冻结）**：按日分组，组内 `L_g = −Σ_k w_k·(o_k − logsumexp_k)`（按 y 降序排列后；
  **未归一加权和**，保留原版「组损失求和 ÷ 组数」结构）——w≡1 时与
  `fterm.model.losses.listmle_loss` **逐位相同**（浮点论证 + W0b 实跑验证）。
- **训练侧一切不变**：折界 `["2019-01-01","2021-01-01","2023-01-01","2025-01-01"]`+面板末 /
  LABEL_SPAN=6 净化 / CrossSectionNet(50，net2) / **按日整批**（day_batches batch_days=1，
  shuffle seed = seed×1000+ep）/ AdamW lr=1e-3 wd=1e-5 / EPOCHS=30 / PATIENCE=5 /
  val=训练段末 15% 纯 MSE 早停 / 5 网种子平均 —— 与 #122 A1、#133 F2 **逐字相同**
  （单变量 = 样本权重）。
- **种子集**：`SEEDS_5 = (7, 21, 99, 5, 13)`（= #27 §二 冻结种子集 = F2 流种子集）。
- **参考臂 F2 = #133（e2mse_full）纯 ListMLE 流**
  （`experiments/e2mse_full_20261014/stream_F2_f4.parquet`；5 种子平均 × 4 折；
  8,055,261 行，2019-01-02 → 2026-09-21，**无 seed 维度**），**不重训**。
  同源证明：EW 执行器 `ew_train_arm_fold` 与冻结实现 `ab_chain.train_arm_fold` 全函数
  diff（唯一差异 = 权重插桩；插桩默认关闭时原路径逐字不变）+ w≡1 实跑逐位复现（W0b）；
  diff 全文存 `experiments/ewlistmle_20261016/executor_diff.txt`。
