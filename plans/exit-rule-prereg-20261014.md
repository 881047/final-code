## §1 判据（**冻结，全部先于跑数**）

| 门 | 判据 | 门槛 | 判负 |
|---|---|---|---|
| **G0 仪器** | ①exit_fn=None 与未改版 arm_faithful **逐位一致**（回归钉 + 同批 A0 双跑对账 max\|Δequity\|=0）；②n_blocked_cash=0（四臂）；③同输入确定性重跑 max\|Δequity\|≤1e-9（A1 臂） | 全过 | 任一失败 ⇒ **全链作废**先修仪器 |
| **S1 信号层 ⭐** | 退出触发事件收益：A1/A2/A3 各自的退出触发标的，触发日→下次调仓日的实际持有段收益 bp 序列，NW t | **t ≤ −1.64**（单侧 95%，方向=退得对）且 \|点估计\| ≥ 11.5bp（#31 锚 −23.0bp h=5 的保守折半；锚口径与本链持有期差异已声明） | t > −1.64 ⇒ 该臂信号层无依据 |
| **C1 成本门 ⭐** | A_k − A0 月度对数收益配对（`monthly_chain.monthly_log_paired`）+ 成本调整后增量 | 配对 t ≥ 2 且 mean_log > 0 且（毛收益差 − Δ成本折算）> 0；成本锚 = 实际单票金额口径（w2 top-2 预算 ≈9,500 元 ⇒ 往返 17.1bp，`avoid_value_chain` 口径） | 调整后增量 ≤ 0 ⇒ 该臂判负 |
| **S2 稳健门** | 前半（2019-01~2022-12）vs 后半（2023-01~2026-09）C1 方向 | 两半段同号（≥0 或 ≤0 一致） | 异号 ⇒ 该臂判负（#63 时段教训） |
| **NEG 阴性** | 同换手率随机退出带：按 A1 实际退出事件数，在同臂持仓上随机选等量退出（种子 20261015，预生成） | A1 显著优于 NEG（S1 口径 t_gap > 0）且 NEG 与 A0 的 C1 不可分（\|t\|<2） | A1 ≈ NEG ⇒ 机制不存在 |
| **R 组合层** | 总收益/MDD/换手/部署率：**只报告不裁决**（#24 R1-R5 标注 MDE）；F 监控：A_k MDD − A0 MDD | 恶化 >5pp ⇒ 判决词警告；>10pp ⇒ 建议不采纳 | — |
| **TR 触发率（登记义务）** | A1/A2/A3 退出触发率（触发事件/持仓·调仓日） | 如实登记 | **A1 触发率 < 1% ⇒ A1 判「机制不可达」**（A2/A3 照跑） |
| **通过（臂级）** | G0 ∧ S1 ∧ C1 ∧ S2 ∧ NEG(仅 A1) | ⇒ 该臂出**采纳建议**（切换退出规则 = 独立生产改动 + docs/02 登记，待用户拍板） | 任一失败 ⇒ 该臂登记关闭 |

## §2 止损（**冻结**）

- G0 任一失败 ⇒ 全链作废（不判候选）；
- A1 触发率 < 1% ⇒ A1 判「机制不可达」登记关闭（A2/A3 照跑）；
- 全部臂 C1 调整后增量 ≤ 0 ⇒ 整链判负登记关闭（结论：「退出带重构无增量」本身是有效登记）。

## §3 明确不做

1. 不改 config.yaml（退出参数/信号位零改动；采纳 = 独立拍板）；
2. 不测每日触发变体、不测动态阈值；
3. A1/A2/A3 同批跑完，**不中途择优、不加臂**（防 garden-of-forking-paths）；
4. 组合层读数不裁决、不推断年化收益；
5. 不追溯任何历史 tierfix/w2_rule 读数。
