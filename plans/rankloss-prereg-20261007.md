# 判据链 #14 预注册 · 训练目标对齐——rank-loss 臂（2026-10-07 冻结，跑数前定稿）

> 依据：#13 判决后的架构审查（2026-10-07）。发现训练目标与评价/下游目标错配——
> 训练损失 = 逐票 MSE on 5 日前向收益（dlv2_chain.py:134），而评价与组合层
> 全部消费**截面秩**（RankIC 选 top10/keep20，EMA 平滑秩）。MSE 被极端收益样本
> 主导，不优化排序。本链只动**一个变量：训练损失**，其余全部逐字沿用 #8 口径。
> 背景：batch=4096 跨日混洗下，同日对期望覆盖率约 0.24%/epoch/日对空间
> （折 0 每 batch ≈ 1.8 万同日对、折 3 ≈ 4400 对），足以支撑 batch 内
> pairwise 秩项，**无需改 batch 构型**——避免损失/批构型双重改动混淆归因。

## 一、机制（实现语义冻结）

- **臂 B（rank-loss）**：在 #8 训练路径上，损失 = `mse_mean + rank_mean`（λ=1，
  两项各自 batch 均值）。`rank_mean` = RankNet pairwise logistic：batch 内按
  day_id 稳定排序后取**相邻对**（i, j）中 day 相同且 y_i ≠ y_j 者，
  `softplus(-(s_i−s_j)·sign(y_i−y_j))` 的均值（s = 网络输出）。种子/天数洗牌
  用全局 torch RNG（manual_seed 同 #8），对采样由 batch 内排序决定 ⇒ 全程确定。
- **其余全部冻结同 #8**：CrossSectionNet 架构常量、fold_frame（逐日截面秩白化 +
  缺失指示 + LABEL_SPAN×2 净化）、fit_bins/to_bin_idx、BATCH=4096 混洗、
  LR=1e-3、WD=1e-5、MAX_EPOCHS=30、PATIENCE=5、**早停与模型选择 = val MSE**
  （与 #8 同一口径——只有训练梯度变，选模不变，隔离损失效应）、
  折界 2019/2021/2023/2025、START_OOS=2019-01-01、双种子集
  {7,21,99,5,13}/{123,2024,42,314,2027}、测试段全截面预测。
- **对照（不重训）**：已缓存 MSE 流 `data/reports/dlv2_ss{7_21_99_5_13,
  123_2024_42_314_2027}.parquet`（#8 产物，同折界同口径）。

## 二、仪器检查（先于一切判读）

- **X0 仪器位连检查（2026-10-07 erratum 版，见下）**：缓存 MSE 流折 0 行的
  **行集合与标签**必须与今日 `fold_frame` 重算结果逐位一致
  （行集合差 = 0 且 max|Δy| = 0）；特征值层面由 2026-10-07 worktree 探针覆盖
  （ffea601 重构前代码 vs 现行代码，折 0 训练帧 X/miss/y/meta 逐位一致，
  证据存档证据包）。违反 ⇒ 数据/特征仪器漂移，全链判废。
  **erratum 记录（先于全量跑）**：原判据"原版重跑 preds 与缓存逐位一致
  （max|Δpred|==0）"实测不可达——同机同码同种子背靠背两次训练即
  max|Δpred|=2.79e-03（1,688,725/1,688,732 行不等），val MSE 亦不同
  （0.006304 vs 0.006298）⇒ GPU 训练路径非确定（BatchNorm/Embedding 反向
  atomicAdd）。X0 重跑实测 max|Δ|=1.97e-03，与同日重跑包络同量级，属训练噪声
  非仪器漂移。#12 当年"逐位自证通过"实为组合层锚（消费缓存流、无训练），
  未检验过训练路径。处置：X0 改为上述位连检查（较原判据在数据/特征层面更强），
  训练噪声包络 2.79e-03 入档；本 erratum 与 #12 误报取证（docs/03 §26）同先例。
- **阴性对照（erratum #3，2026-10-07）——孪生设计**：同一置换种子（20261007）
  下训练 λ=1 与 λ=0 两个 shuffle 臂（折 0 × 种子 7），**判停条件（tripwire）**：
  两臂 |mean IC| < **0.025**（= 真实信号尺度 0.05 的一半；真泄漏——置换未生效
  或标签通路被打穿——会落在 ≈0.05）；两臂 shuffle 流落盘证据包。
  λ1 与 λ0 的配对差作为**处理性质**登记（结构放大效应），不判停。
  **erratum 依据**：①λ0 孪生实测 mean IC=-0.00129（置换机制无懈可击）；
  ②λ1 同置换 +0.01408，配对差 t=+10.45——秩项与 MSE 项消费**同一 yb 张量**，
  不存在秩项单独的真标签通路；+IC 的机制 = 秩损失对日内偏移不变 ⇒ 训练容量
  集中于日内排序结构 ⇒ 把特征中存活的截面暴露放大出来（结构放大效应），
  属处理性质而非仪器故障；③分解证据：λ0-shuffle IC(pred,|y|)=+0.024、
  λ1-shuffle=-0.017、真实 MSE 流=-0.037（波动暴露结构真实存在）。
  前两次判停（0.005 绝对阈、3σ 自校准规则）均因该效应在设计上必然触发，
  判据被重定义为只检验"实现是否见到真标签"。
  **对 P1 的解释约束（登记）**：若 P1 过线，λ1 优势中可能包含部分标签无关的
  结构放大成分——adoption 语义（前瞻纸面 ≥60 交易日）本就以未见数据为最终
  裁判，不受此影响，但判决词应知情。

## 三、判据（冻结）

主判据（B vs 缓存 MSE，同种子集配对）：

- **P1（日频 IC 轴）**：逐日 RankIC 差（B − MSE，按日配对，两流共有行）的
  paired t ≥ 2 且均值 > 0，**双种子集都过**；
- **P2（组合层轴）**：两臂各自 2 种子集均值预测面板 → 同一组合层
  （`run_model_arm(-1e9, 10, 10, cfg, ·)`，与 #13 集成臂同构）
  → 月度对数配对（B − MSE）t ≥ 2 且均值 > 0；
- **adoption_ready = P1 ∧ P2**。过线 ⇒ 判决词 + 生产工件换版流程
  （train_production 重训为 rank-loss 版本、新哈希留痕、双轨账本记录版本号），
  **不自动替换**；不过 ⇒ MSE 训练目标封顶登记，rank-loss 线结清。

透明读数（不设门，全部报告）：

- per-set 绝对 IC、组合层两臂各自收益/MDD/成本、
- C1-C4 风格门 vs 显式基线 **S1_20w_top2**（20 万档 top2 规则 S1，
  即 #13 实际执行的基线；报告改名以消除 #13 的 S1_T3 标注歧义）；
- 多重比较声明：2 种子集 × 2 轴一次报告，无事后挑臂；新增任何臂须新预注册。
