## §1 A2 · 分桶数扫描（**单变量**）

| 臂 | `N_BINS` | 说明 |
|---|---|---|
| **B16** | 16（**基线**）| 现行值 |
| **B8** | 8 | 桶更粗 |
| **B32** | 32 | 桶更细 |
| **B64** | 64 | 最细（检验 §66 的"右尾需要分辨率"假设）|

**实现**：`net2.N_BINS` 是模块级冻结常量 ⇒ 变体须**新建模块**（`net2_bins.py`），
**不改 `net2.py` 原件**（沿用 P1 的纪律；`net3`/`net4` 都 import net2）。

**⚠ 关键假设（来自 #66 A2）**：本项目"IC 增益落在截面中段、不在右尾"，
而右尾最依赖分辨率 ⇒ **桶数越细，右尾判别应越好**。
⇒ 预注册**方向性预期**：B32/B64 的**右尾**读数应优于 B16。
**若 B64 的右尾也不动 ⇒ 该假设被证伪 ⇒ A2 结清。**

|---|---|---|
| **R** | ReLU | **基线**（`net2.py:82-83`）|

## §3 判据（**冻结，逐字沿用 P1**）

| 编号 | 判据 | 门槛 |
|---|---|---|
| **M1 ⭐主** | ICIR（vs B16/R 基线） | **≥ 基线**（非严格显著）|
| **M2** | 右尾（top 0.5% 篮子周均） | **≥ 基线** |
| **M3 次** | 信息层逐日 RankIC 配对 t | **NW-t ≥ 2** |
| **M4 过拟合门** | PBO | **口径不适用**（N=2 伪读数，见 §70）⇒ **本批不作为门**，只作参考读数 |
| **M5 稳健** | 逐折 IC 全正 + regime 分层 IC 最小值 > 0 | 全正 |

**通过 = M1 ∧ M2 ∧ M5**（M3 为信息层门槛；M4 本批口径不成立，见 §70 已加固的 `N<4` 守卫）。

**⚠ 提前结清（硬约束）**：若某变体出现「IC 升、ICIR 与右尾同时不动」
⇒ **该杠杆结清**，不追加更多档位。

**⭐ 多重检验**：A2 有 3 个变体（8/32/64）、A3 有 1 个 ⇒ **每族内做 Bonferroni**
（A2 族 3 个 ⇒ ICIR/右尾的方向性判定按 `α/3`；A3 族 1 个 ⇒ 无需校正）。
**⚠ 诚实登记**：ICIR 的"≥基线"是方向判定而非显著性检验 ⇒ **校正只作用于"是否值得追"的判断，
不改变"ICIR 是否低于基线"这一事实**。
