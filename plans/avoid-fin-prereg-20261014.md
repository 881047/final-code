# 预注册 · 判据链 #132 · **判弱因子买入前过滤（模型外规则）**（B 系列 B9 · 用户拍板提前）（2026-10-14 冻结）

> **触发**：#79 确立 `fin_netprofit_yoy` 为最强判弱侧候选（低增速 −18.53bp t=−3.73、
> 覆盖 78.8%、W4 无时段衰减、W5 正交 23/23、**PIT 已复核 #80 三层全过**）；#84 证其
> **入模**判负（ΔIC=−0.0021）⇒ 唯一未测形态 = **模型外买入前过滤**。#128（B1）判负后，
> 本链是判弱侧兑现的**唯一剩余通道**（退出侧已证无自由度：keep4 先于任何弱档阈值截断持仓）。
> **性质**：组合层构型 A/B（双臂）。跑数前本文件先 commit 冻结。
> 执行目录：`experiments/avoid_fin_20261014/`；执行器 `scripts/avoid_fin_chain.py`；

## §0 对象与规则（**冻结**）

| 项 | 冻结内容 |
|---|---|
| **过滤因子** | `fin_netprofit_yoy`（`data/external/fin_netprofit_yoy.parquet`；#80 PIT 复核通过版；极性：**低值 = 弱**，#79 W0） |
| **过滤规则 F1** | 每调仓日，买入候选 = `ranked.head(K)` 内顺延选取，K=50；**剔除**：因子值存在 **且 ≤ 当日截面 10% 分位**（低增速命中）的标的；命中被跳过后继续向下找（同 B7 顺延语义）；候选耗尽（50 个全被剔或买不起）⇒ 少买/不买 |
| **缺失处理** | 因子缺失（覆盖 78.8% ⇒ ~21% 缺失）= **放行不过滤**（最小干预；冻结，不做缺失=跳过变体） |
| **分位口径** | 因子在当日**全截面**（有值股票）的 pct-rank ≤ 0.10（与 AVOID-10 同款绝对分位语义） |
| **对照 A0** | 现行买入（无过滤，同批重跑） |
| **构型/节律** | w2 冻结构型；`ema_step=daily`；周五调仓节律不变；RL2 10-14 流；面板 ≤2026-09-30 |
| **退出侧** | **不动**（keep4，#128 已证退出侧无自由度）——本链单变量 = 买入前过滤 |

## §1 判据（**冻结，先于跑数**）

| 门 | 判据 | 门槛 | 判负 |
|---|---|---|---|
| **G0 仪器** | ①A0 与未改版 arm_faithful 逐位（回归钉 + 同批双跑）；②确定性重跑 max\|Δeq\|≤1e-9；③blocked_cash=0 | 全过 | 失败 ⇒ 全链作废 |
| **S1 信号层 ⭐** | **被过滤标的** vs **实际买入标的**的同期持有段收益差（触发日→下次调仓日，收盘口径）：被跳过者应更差 | 配对差 NW t ≥ +1.64（方向=过滤正确）且点估计 ≥ 11.5bp（#128 同款保守锚） | t < 1.64 ⇒ 机制无依据 |
| **C1 成本门 ⭐** | F1 − A0 月度对数收益配对 + 成本调整后增量（卖笔差 × 9500/20000 × 17.1bp） | 月度 t ≥ 2 且 mean_log > 0 且净差 > 0 | 调整后 ≤ 0 ⇒ 判负 |

| **FR 过滤率（登记）** | 触发过滤的事件数 / 调仓日数 | 如实登记 | **0 触发 ⇒ 机制不可达判负** |

| **通过** | G0 ∧ S1 ∧ C1 ∧ S2 | ⇒ 出「买入侧过滤进生产」建议（docs/02 + 用户拍板） | 任一失败 ⇒ 登记关闭 |

## §2 止损（**冻结**）

- 全史过滤事件 = 0 ⇒ 机制不可达，登记关闭；
- S1 方向为负（被跳过者反而更好）⇒ 判负关闭——**该读数本身有信息量**（fin 因子低分位
  在 top 候选内的条件分布 ≠ #79 的无条件读数，如实登记）。

## §3 明确不做

1. 不动退出侧、不动信号位、不改 config；
2. 不测其他 3 个因子（fc_dir 等——单因子单假设，防 garden；fin_netprofit_yoy 是
   #79 唯一「覆盖+t>3.7+无衰减+正交+PIT」全过候选）；
3. 不测阈值变体（10% 分位单一冻结）；缺失不放行变体不做；
4. 组合层读数不裁决；不追溯 #84 入模判负（形态不同）。
