## 每日运行时序

| 时间 | 动作 | 命令 |
|---|---|---|
| 15:30 收盘后 | 面板同步（老库只读）→ 决策循环（paper） | `scripts\run_daily.py` |
| 15:35 | 看板确认决策与告警 | http://127.0.0.1:8787/#/fterm（NEW ECO 全账户页） |
| 每周五 | 全量重训 + walk-forward 报告 | `scripts\train_model.py` |
| 常驻 | watchdog 探活（心跳 3×10 分钟超时告警） | `check_once(cfg)` |

- 计划任务 `fterm_daily`（工作日 **20:05**，2026-10-05 起；原 19:35 与老盘日链
  尾巴 19:41 竞态）→ `run_daily_task.bat` →
  `scripts\run_daily_auto.py`：sync → **数据就绪闸**（不过 = exit 2 不落账，见下
  「2026-10-05 数据就绪闸」节）→ asof=面板最新交易日 → `run_daily
  --asof 该日 --skip-sync`；幂等（日志严格超前才退出，同日 REPLACE）。
  **上游数据由老盘每日链更新，本仓只读，不做任何网络拉取。**
- 桌面快捷方式（2026-10-07 起）：**fterm 每日运行** → `scripts\run_daily.bat`。
  （原 **fterm 看板** 快捷方式随 8790 看板线退役，同日删除。）
- `.bat` 注释必须 ASCII（cmd OEM 码页坑，2026-09-26 实测）。
- **看板线已退役（2026-10-07）**：本地 8790/8791 看板（`scripts\serve_board.py`、

### 2026-10-05 数据就绪闸（run_daily_auto）+ 计划任务档期 19:35 → 20:05

  up_limit 覆盖到 close 最新日（拒"撮合静默回退近似停板价"的降级口径落账）；

  回测/训练不受影响。
