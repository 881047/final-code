## §2 问题清单

### §2.1 P0（阻断信息层升级）

**P0-1｜主判据当前无法度量（最严重）**
- 现象：项目声称「α 的时间结构是瓶颈」，但验证栈只有单点 walk-forward + 平均 IC。
- 证据：
  - `fterm/model/validate.py:23-53` `FoldMetric` 只有 `dir_acc/rank_ic/q_coverage/val_loss`；`_daily_rank_ic:80-92` 只取**均值**。
  - `scripts/dlv2_chain.py:157-168` 只算平均 RankIC + 一个 `C1: ic_mean>0.02` 布尔。
  - `scripts/judgment_chain.py:79-93` `info_layer_metrics` 只有 `rank_ic/rank_ic_t/dir_acc/q_cov`。
  - 全仓 grep `ICIR|CPCV|PBO|Deflated|regime` → **零命中**（仅 docs/03 文字提及）。
- 影响：**无法度量 ICIR、滚动 IC 稳定性、制度分层 IC、过拟合概率**——而这正是用户指定的主判据。
- 处置：Phase 3 从零建度量栈（`cpcv.py`/`stats.py`）。

**P0-2｜目标函数与选模指标错配**
- 证据：`scripts/train_production.py:106-116` 损失 = `MSE + LAMBDA_RANK(1.0) × RankNet`，但早停/选模 = **纯 val MSE**（`vl = mse_loss(...)`）。
- 旁证：`plans/tailloss-prereg-20261008.md` §一自述「梯度由秩项主导、选模看回归指标」；#18 的 M1（改 val RankIC）判负，但**错配本身未修**。
- 影响：选模点与训练目标不一致，是「IC↑ 而组合层不涨」的候选机制之一。
- 处置：Phase 2-E 统一为排序型选模，且选在 CPCV 上而非单点 val。

**P0-3｜训练非确定，且无包络纪律**
- 证据：docs/02（2026-10-08 登记）「同机同码同种子背靠背两次训练 `max|Δpred|=2.79e-03`」（BatchNorm/Embedding 反向 atomicAdd）；`experiments/rankloss_20261007/x0_attribution.json` 归因确认为 GPU 非确定。
- 影响：单变量归因实验若无确定性开关或包络声明，读数不可信（#18 曾因 F0 锚点结构性不可达而返工）。
- 处置：确定性算法开关 + 「包络纪律」；单变量对照统一用**同码新鲜 F0**。

**P0-4｜秩化通道在进入网络前消灭市场状态的截面信息**
- 证据：`fterm/model/foldframe.py:117-123` 与 `fterm/model/infer.py:52-56` 对**每一列**做逐日截面秩白化。
- 机制：任何**横截面常数**特征（`weekday`、`disp_20`、指数收益、市场广度）在同一日的截面秩**无变异**
  → 白化后**同日截面零方差** → 无法区分个股 → **对截面排序零贡献**。
- ⚠️ **更正（2026-10-09 实测）**：初稿写「白化后恒为 0」**不准确**。live 管线用的是
  `√2·erfinv(p)`（**非**文档所写的 `√2·erfinv(2p−1)`，见新增 P0-6），故常数特征映射到
  **常数非零值**（如 p=0.5833 → 0.8122），而非 0。**结论不变**：零截面方差 ⇒ 对排序无贡献。
- 影响：**这是「市场状态非秩通道」必须旁路 rank 的根本原因**，也是 §40 点名方向的可行性前提。
- 处置：Phase 2-A 在 `foldframe.py` 新增旁路通道 `Z`（不做 rank，仅按训练段 mean/std 标准化）。
  已实现并由 `tests/test_foldframe_z.py` 钉住（零截面方差 + 旁路保留原值）。

**P0-6｜文档化的 Rank-Gauss 是死代码，live 管线用了另一种白化（新发现）**
- 证据：
  - `fterm/model/net2.py:23-36` `rank_gauss()` 实现的是**文档所述**的 `√2·erfinv(2p−1)`（QPLUM 式，p=0.5→0）；
  - 但 `rank_gauss` **全仓无调用方**（`scripts/dlv2_chain.py:28` 仅 import，无 call）——**死代码**；
  - live 训练路径 `fterm/model/foldframe.py:123,168` 与推理路径 `fterm/model/infer.py:56,122`
    实际计算 `√2·erfinv(p)`（**漏了 `2p−1`**）。
- 实测：`net2._erfinv(0.5833) = 0.5743`（scipy erfinv 直传），而 `√2·erfinv(2·0.5833−1) = 0.2104`。
- 影响评估：**非功能性故障**——训练与推理用同一变换，模型自洽可学。但：
  ① 项目自述的方法学（docs/plans 引 QPLUM「erf⁻¹(2p−1)」）与实际计算不符，属**文档-实现漂移**；
  ② 该变换**不对称**（中位数 p=0.5 → +0.6745 而非 0），全部特征带正偏置；
  ③ 是 P0-4「常数特征归零」这一直觉判断失准的直接原因。
- 处置：**不擅自修改**（改白化 = 改基线，须走 docs/02 参数基线登记 + 全量重训）。
  **用户 2026-10-09 拍板：先保持现状**（live 口径 `√2·erfinv(p)` 不动）。
  理由：训练/推理自洽，非功能性故障；改为独立变量留待臂 A 之后单独检验。
  臂 A 在两种口径下均可跑（旁路通道的必要性不依赖此差异）。

**P0-5｜外部数据无 PIT 守卫（尚未引入）**
- 证据：`fterm/data/external.py` 不存在；外部源无统一发布日期列（`analyst/` 尤甚，仅 `eps_2026/27/28`）。
- 影响：若直接接入，极易前视泄漏。
- 处置：Phase 0b 建 `external.py`，强制 `shift(1)`/`ann_date`/`ask_ts` + 覆盖断言 + 置换阴性对照；无时间戳源不接入。

## §3 模型层根因分析（为何 5 次模型层尝试全负）

台账 §40/§43 记录了 5 次模型层改进尝试（#14 rank-loss、#18 选模指标 + 尾部加权、以及更早的若干），全部未产生可采纳改进。归因如下（按解释力排序）：

1. **目标-选模错配**（P0-2）：梯度由秩项主导，选模却看回归 MSE → 选出的 epoch 不是秩最优。
2. **秩化信息损失**（P0-4）：市场级/制度级信息在进入网络前被 rank 消灭 → 模型**结构上无法**条件化于制度。
3. **单 horizon**：h=5 是信噪比最差的档（#7：h1 IC 0.032 → h21 IC 0.078，单调升）→ 目标本身噪声大。
4. **无状态通道**：即使有制度信息也进不去（P0-4 叠加 P1-1）→ 模型无法按制度切换。
5. **无截面交互**：个股间相对定价（同行业/同题材的横截面关系）未被建模。

**关键判断**：这 5 条中，1/3/5 是「模型层」，但 2/4 是「**特征-输入管道层**」。§43 说「模型层的损失函数与选模指标不是当前杠杆」是对的，但这**不等于模型层无改进空间**——它意味着**必须同时改输入管道（旁路通道）与目标结构（多 horizon）**，而不是继续在损失函数上做文章。本计划据此把杠杆放在 A（旁路通道）+ B（多 horizon）+ C（新数据）上。

- 逐日配对 t（A−F0）= **+1.03**（ΔIC = +0.0045）→ **未达预注册门槛 t ≥ 2**。
- **ICIR 反而下降**（0.652 → 0.578）→ 滚动稳定性门**不通过**。
- `adoption_ready = False`（三门中仅"regime 分层 IC 全正"通过）。

**结论（如实）**：市场状态非秩通道**提高了 IC 约 10%（+0.0045）且不破坏分层符号**，
但**未达统计显著**，且**削弱了用户指定的主判据 ICIR**。以本次实现（FiLM + 11 个市场级特征
+ 2 种子 + MSE）**不足以采纳**。

**重要教训（方法论）**：单折冒烟曾给出 ΔIC = +0.0235、配对 t = +8.10 的**假阳性**——
原因是训练窗仅 2017–2019（2 年），基线 IC 被压到 0.0156，条件化通道趁机"补"了大量
本应由更长训练窗提供的信息。四折基线 IC = 0.0447（与文档 dlv2 的 0.0485–0.0579 同量级），
条件化增益随之缩水到不显著。**这再次证明：单折读数不可作为裁决依据**（本项目预注册纪律的正确性）。

**方向未完全关闭**：本次只测了 FiLM 一种注入方式与一组固定 Z 特征。
条件 LayerNorm、门控 MoE、不同 Z 特征集、以及 14 种子集成均未测；
但按 §43 的教训，**不应把"再换一种注入方式"当作主要杠杆**——更可能是
"市场状态对**截面排序**的边际信息确实有限"。

### §7.5 臂 B 首跑事故：全 NaN 预测 + 两个真实缺陷（**该臂首跑读数作废**）

臂 B 首跑（`verdict_20261009_1350.*`）报告 `adoption_ready = True`、配对 t = **+2.74**。
**该读数无效，已作废**。核查发现预测列在流中**非空数 = 0**（7,977,423 行全 NaN）。
IC 之所以算出 +0.0578，是因为 `spearman_rank_ic` 对全 NaN 输入会把 NaN 排到末尾并赋予
非恒定秩，退化成"**行序 vs 收益序**"的伪相关（行按代码序排列，天然有非零相关）。
五个头 IC **完全相同**（+0.0578）正是这一退化的指纹——真实的多头模型不可能如此。

**根因链（两个真实缺陷）**：

1. **`build_multi_y` 列对齐错误（新代码）**：标签面板 `fwd_ret_h*` 由 `open×adj` 派生
   （**5471** 列），而特征参照面板为 **5467** 列；直接 `arr[ri, ci]` 索引错位，取到含 NaN
   的格子 → MSE 损失变 NaN → 网络发散 → 预测全 NaN。修复：先把标签面板
   `reindex(index=master, columns=codes)` 再索引。**这是本次会话第三次遇到同类列集不一致问题**
   （前两次：`newdata_chain`、`external.py` 的 up/down_limit），说明"面板列集异构"是本项目
   一个**系统性陷阱**，只有 `fold_frame._align_panel_cols` 做了显式对齐。

2. **`spearman_rank_ic` 静默接受 NaN（既有代码，潜在缺陷）**：原实现直接用 `np.argsort` 排 NaN，
   NaN 被排到末尾并获得非恒定秩 ⇒ **全 NaN 输入也返回一个看似正常的 IC**。
   已修复（先剔除任一侧非有限的样本对），并加 `tests/test_spearman_nan.py` 6 项回归钉。
   **影响面**：这是项目核心指标函数，任何含 NaN 的预测/标签都可能被静默转成伪 IC。
   已复核臂 A / 臂 C 的流（预测与标签均无 NaN），**其读数不受影响**。

3. **样本集口径不完整（新代码）**：仅按最长 horizon（h=20）过滤不足——个股在 t+2 停牌而
   t+1/t+21 正常交易时 h=1 为 NaN（实测 1018/1,091,266）。已改为**所有 horizon 的交集**。

4. **不确定性加权退化（设计缺陷）**：Kendall(2018) 可学习加权在本任务上**单调发散**
   （train_loss 从 ~0 一路降到 −12，log σ→−∞）——因 L 可趋 0 时 `0.5·exp(−s)·L + 0.5·s`
   关于 s **无下界**。已改用「**标签按训练段 std 标准化 + 固定等权**」，并在本报告登记此偏离。

**结论**：臂 B 的有效读数**尚未产生**（修复后重跑中）。首跑读数作废，
不得引用其 +2.74。

7,960,165 条 OOS，**流校验 100% 非空**，5 个头预测全部有效）。

|---|---|---|---|

### §7.7 臂 C · 14 种子确证性实验：**判负，且假设被证伪**

证据包 `experiments/armC14_20261009/verdict_20261009_2358.*`
（14 种子 = 生产位种子池逐字相同 / 4 折 / 两臂各 8,055,261 条 OOS / 总耗时 9.5 小时）。

| 臂 | IC | NW-t | ICIR |
|---|---|---|---|
| F0_14（25 特征，14 网） | +0.0595 | +13.94 | +0.623 |
| **C_14（32 特征，14 网）** | **+0.0629** | **+15.05** | **+0.665** |

- 逐日配对 t（C_14 − F0_14）= **+1.61**（ΔIC = +0.0034）→ **未达门槛 t ≥ 2**
- regime 4 层分层 IC 全正（最小 **+0.0523**）✓
- **PBO = 0.800**（70 个划分）→ **劣于 2 种子时的 0.514**，无可靠选择优势
- `adoption_ready = False`（主判据与 PBO 两项均不通过）

#### 关键发现：**"加种子"假设被证伪**

预注册的假设是「集成方差随种子数下降，配对 t 有望越过 2」。实测**否定了该假设**：

| | 2 种子 | **14 种子** |
|---|---|---|
| F0 IC | +0.0447 | +0.0595 |
| C IC | +0.0514 | +0.0629 |
| **ΔIC（绝对）** | +0.0067 | **+0.0034** |
| **ΔIC（相对）** | **+15.0%** | **+5.7%** |
| **配对 t** | **+1.66** | **+1.61** |
| PBO | 0.514 | **0.800** |

**三条含义（如实）**：

1. **配对 t 几乎未变**（1.66 → 1.61）。集成规模从 2 网扩到 14 网**没有**带来显著性提升。
2. **相对增益反而缩水**（+15.0% → +5.7%）。这说明 2 种子时观测到的 +15% 中，**相当一部分是集成噪声**，
   而非特征的真实增量 —— 这正是本次确证性实验的价值所在。
3. **PBO 恶化**（0.514 → 0.800）。说明 C 相对 F0 的**排序优势在时间上不稳定**：
   在 80% 的 IS/OOS 划分中，样本内更优的臂在样本外反而更差。

**正面项**：ICIR 改善（0.623 → 0.665，+6.7%），且 regime 各层 IC 全正。
即臂 C **确实改善了稳定性维度**，但**未改善到统计显著**，且**PBO 显示其排序优势不可靠**。

#### 结案（依预注册 §三）

预注册明定：「若主判据不通过 ⇒ **臂 C 判负并结案**，不再做'加更多种子/换种子集'的尝试。」
**本次严格照此执行，臂 C 结案。**

**补充说明（Bonferroni）**：预注册 §五已登记，这是臂 C 的第 2 次检验，
若要保持族错误率门槛应≈ **t ≥ 2.24**。实测 t = 1.61，**即使按未校正的 t ≥ 2 也不通过**，
故门槛宽严之争在此**不影响结论**。

## §9 最终结论（2026-10-09 收束）

**九次干预（历史 5 次 + 臂 A / B / C + 臂 C 的 14 种子确证）全部未达预注册门槛。**

| 干预 | 类型 | 结果 |
|---|---|---|
| #14 rank-loss 等（历史 5 次） | 模型层 | 判负 |
| 臂 A 市场状态非秩通道 | 输入管道 + 架构 | 判负（ICIR 劣化） |
| 臂 B 多 horizon 融合 | 目标结构 | 判负（ICIR 腰斩） |
| 臂 C 外部日频因子（2 种子） | 信息面 | 判负（t=1.66） |
| 臂 C 外部日频因子（14 种子） | 信息面 | **判负（t=1.61，PBO 0.80）** |

**核心判断**：本项目的瓶颈**确证**为 **α 的时间结构**，而非模型容量、损失函数、架构复杂度或特征数量。
**在此结论下，不具备换版依据** —— 现有 `dlv2_production.pt` 应**保持不动**。

**本次会话的净产出**（即使全部判负，仍有实质价值）：
1. 建立了项目此前**完全缺失**的验证栈：ICIR / CPCV / 制度分层 IC / PBO / Deflated Sharpe；

4. 从老库提炼出 **37 个日频因子**并筛出 7 个幸存者，其中 `hk_ratio_chg5`

   直接比**（跨口径，见 §7.2 erratum）；
5. **用确证性实验证伪了"加种子能提升显著性"的假设**，避免了一次基于噪声的换版决策。
